# Remix of Fortaleza Cooling

Landing Page - SG Ar Condicionados

Crie uma landing page de alta conversão para geração de leads.

Tecnologias

Não utilize a stack padrão do Lovable (React, Vite, Tailwind ou frameworks).

Desenvolva o projeto utilizando apenas:

HTML5

CSS3 puro

JavaScript Vanilla

O código deve ser limpo, organizado, sem bibliotecas externas desnecessárias e separado em arquivos:

index.html

style.css

script.js

A landing page deverá ser totalmente responsiva, possuir excelente desempenho (Core Web Vitals), carregamento rápido e SEO otimizado.

Objetivo da página

Esta NÃO será uma página institucional.

Ela será uma Landing Page focada exclusivamente em vender um único serviço:

Manutenção de Ar Condicionado Residencial.

Todo o layout, copywriting e chamadas para ação devem existir apenas para levar o visitante a solicitar um orçamento pelo WhatsApp.

A única conversão desejada é o clique no botão de WhatsApp.

Fortaleza - Ceará

Essa informação precisa aparecer diversas vezes ao longo da página para eliminar qualquer dúvida do visitante sobre a região atendida.

Estrutura da Landing Page

1. Hero Section

Imagem de um técnico realizando manutenção em um ar-condicionado.

Headline extremamente forte.

Exemplo de conceito:

"Seu Ar Condicionado Parou de Funcionar? Resolvemos Rápido em Fortaleza."

Subheadline destacando:

atendimento rápido

orçamento sem compromisso

técnicos especializados

Botão principal:

"Solicitar Orçamento pelo WhatsApp"

Adicionar pequenos elementos de confiança como:

Atendimento em Fortaleza

Atendimento rápido

Profissionais especializados

2. Sessão de Problemas

Mostrar situações comuns:

✓ Ar não liga

✓ Não está gelando

✓ Vazando água

✓ Cheiro de queimado

✓ Muito barulho

✓ Pouca refrigeração

✓ Mau funcionamento

Cada problema pode possuir um pequeno ícone.

3. Benefícios

Mostrar claramente os benefícios.

Exemplos:

Atendimento rápido

Diagnóstico especializado

Profissionais experientes

Equipamentos adequados

Serviço com qualidade

Atendimento residencial

4. Como funciona

Criar uma seção simples em 3 passos.

Você envia uma mensagem.

Fazemos o diagnóstico.

Realizamos o reparo.

⭐️⭐️⭐️⭐️⭐️

"Pronto atendimento, problema resolvido."

⭐️⭐️⭐️⭐️⭐️

"Competência, compromisso entre outras tantas qualidades... Simplesmente nota mil para vocês."

Criar uma seção com bastante destaque reforçando urgência.

Exemplo:

Botão:

Performance

Priorizar:

carregamento rápido

imagens otimizadas

lazy loading

CSS enxuto

JavaScript mínimo

excelente pontuação no Google PageSpeed

Conversão

Toda decisão de design deve priorizar conversão.

A página deve conduzir naturalmente o usuário até o clique no WhatsApp.

Evite qualquer elemento que distraia o visitante.

Não incluir menu de navegação complexo, blog, páginas internas ou links que retirem o usuário do funil.

O foco absoluto da página é transformar visitantes vindos do Google em conversas no WhatsApp.

Se houver necessidade de tomar decisões de layout, copy ou estrutura, escolha sempre a alternativa que maximize a taxa de conversão.
